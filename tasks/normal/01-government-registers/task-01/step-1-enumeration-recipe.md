# Step 1 — Find the hidden list

## Quick check (first 30 minutes, before deep work)

- [ ] Every page loads; no login, paywall, or CAPTCHA anywhere the recipe must go
- [ ] Main dataset is a normal rich-text site, English as primary language, not on the domain blocklist
- [ ] Prompt is realistic, anchored in a dataset, and timeless
- [ ] **Pinning checked now, not later:** the answer can be pinned to a property inside the data itself, or to a permanent edition. If the only pin available is an "as of" date, an archived snapshot is mandatory. If no pin holds, the preseed is not viable; stop here.
- [ ] **No answer rests on live data.** "Current", "latest", and similar words are subjective and shift; an answer that is true only because of what a live page shows today is not an answer.
