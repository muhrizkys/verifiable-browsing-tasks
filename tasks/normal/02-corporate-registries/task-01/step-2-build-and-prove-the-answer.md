## Rules applied

- Cite the record, never a search form, a filter page, or a page number in a paginated list.
- If a page shows nothing until a search term is typed, record the generic URL plus the exact search term, plus a screenshot of the filtered result.
- If the answer comes from a downloadable file, cite both the file link and the landing page that hosts it.
- An archived snapshot (Wayback Machine) is mandatory for any source that can change: rankings, statistics tables, leaderboards, tour pages.
- At least one screenshot per website used. Every attribute used in the answer or in a predicate must be visible in the evidence, or the screenshot rationale below states exactly where it is verified and how a reviewer reproduces that verification.
- The answer is never based on live data. If a fact can only be read off a live page as it stands today, it is pinned per the Step 1 hierarchy or the task does not proceed.
